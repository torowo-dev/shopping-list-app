# 🛒 쇼핑 리스트 앱

바닐라 HTML/CSS/JavaScript로 만든 간단한 쇼핑 리스트 웹앱입니다.
빌드 도구 없이 `shopping-list.html` 파일 하나만 브라우저에서 열면 동작합니다.

## 기능

- 항목 추가 / 삭제
- 체크박스로 완료 표시 (취소선 처리)
- 완료된 항목 일괄 삭제
- 남은 항목 카운터 표시
- `localStorage`에 자동 저장 — 새로고침해도 데이터 유지

## 사용 방법

저장소를 클론하거나 `shopping-list.html` 파일을 다운로드한 뒤 브라우저에서 엽니다.

```bash
git clone https://github.com/torowo-dev/shopping-list-app.git
cd shopping-list-app
# Windows
start shopping-list.html
# macOS
open shopping-list.html
```

## 파일 구성

- `shopping-list.html` — 앱 본체 (HTML + CSS + JS 단일 파일)
